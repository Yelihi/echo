# Echo · Editorial

2026-10-03 승인 시안: `../2026-10-03-route-concepts/`.
이 문서는 이전 Silver & Ink 디자인 규격을 대체한다.
BrainBox AI 참고의 여백, 가는 선, 정돈된 타이포그래피와 붉은 강조색을 사용한다.

| 역할                 | 기준                                                          |
| -------------------- | ------------------------------------------------------------- |
| 배경 / 면            | #FAFAF9 / #FFFFFF                                             |
| 본문 / 보조 / 구분선 | #202020 / #666666 / #E5E5E3                                   |
| 주요 동작            | #E51E2A, hover #C91520, 흰 글자                               |
| 상태                 | 오류 danger-ink, 성공 green-primary, 경고 yellow-primary 유지 |
| 폰트                 | Inter → Noto Sans KR → system sans-serif                      |
| 제목 / 본문          | Regular, display 40–72px / 기본 16px                          |
| 반경                 | 컨트롤 8px, 패널 10px; 그림자는 메뉴와 모달에 제한            |
| 동작                 | 44px 이상 터치 대상, 명시적인 포커스, reduced-motion 존중     |

1024px 이상은 240px 사이드바, 미만은 상단 바와 모달 메뉴를 사용한다.
목록은 768px 이상 두 열, 미만 한 열이다. 에디터와 준비 화면은 1024px 아래에서 쌓는다.
연습 준비·녹음 화면에는 사이드바를 두지 않는다.

기존 semantic 토큰을 유지한다. `blue-*`, `deep-blue-*`는 기존 중립색 호환 별칭이다.
새 주요 동작에는 `brand`를 사용한다. 시안의 샘플 데이터·파형·점수·재생 버튼은
실제 기능이 있을 때만 표현한다. 저장·인증·분석 계약을 변경하지 않는다.
