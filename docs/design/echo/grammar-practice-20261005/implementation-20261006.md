## 화면과 책임

- `/home`: 세 번째 연습 모드인 어법 연습으로 진입한다.
- `/grammar?q=...&page=...`: 인증된 SSR 목록, 검색·페이지 변경마다 keyed Suspense 로딩을 표시한다.
- `/grammar/new`: 영어 문장과 핵심 어법 설명 → 사전 검사 → 문장 분석 검토 → 저장. 제목·태그는 AI가 작성한다.
- `/grammar/[id]`: 읽기 전용 chunk 선택·풀이, 원문·예문 음성, 예문 생성·검토, 연습 시작, 완료 횟수·기록.
- `/grammar/[id]/edit`: 저장된 분석 편집. 적용하지 않은 내부 편집이 남으면 검토·저장을 차단한다.
- `/grammar/[id]/practice`: 암기/시험 시작 또는 저장된 세션 이어하기.
- `/grammar-sessions/[id]`: 저장된 순서·답안으로 진행. 미완성 시험 문제 생성은 동일 세션에서 재시도한다.
- `/grammar-sessions/[id]/result`: 완료된 세션만 표시. 시험 직후에는 문장별 피드백을 순차 요청하고 실패한 항목만 재시도한다. 기록 재열람은 저장된 결과를 읽으며 자동 유료 생성을 시작하지 않는다.

화면별 상태는 해당 feature/UI에서 소유하며 라우트는 인증된 조회·조합을 담당한다. Tailwind/CVA와 기존 theme 토큰을 사용한다. 홈에서는 사이드바가 없고 어법 모드에서 기존 workspace 사이드바를 사용한다. grammar 화면은 자체 뒤로가기를 제공하며 목록 검색 조건을 등록·상세·세션·결과·기록까지 전달한다. 문장 입력, 분석 내부 편집, 예문 후보 검토의 이탈 확인은 해당 feature가 책임진다.

음성은 사용자가 재생할 때 생성한다. 캐시는 사용자·문장·모델·음성 설정 기준 프로세스 메모리 10분/32개이며 영구 저장이 아니다. 암기 세션에서는 현재 노트를 다시 읽지 않고 소유권을 확인한 당시 세션의 문장을 읽는다. 진행 중 시험 화면에는 원문 정답·음성 UI를 제공하지 않는다.

## 통합 중 보완한 경계

- 미검토 예문을 세션에서 제외하고, 노트 수정 후에도 이전 세션 문장·어법·순서를 유지한다.
- 재시도는 같은 요청 ID를 사용하고 성공 이후 새 연습은 새 ID를 사용한다.
- 원문의 앞뒤 공백과 UTF-16 구간 오프셋을 보존한다. 문장/시험 답안은 4,000자, 부분 회상 JSON은 직렬화 오버헤드를 위한 별도 상한을 적용한다.
- 완료 기록 재조회 시 횟수와 최근 날짜를 함께 갱신한다.
- shell의 main 랜드마크를 재사용하고 중첩 main을 제거한다.
- 시험 입력·결과도 practice theme 토큰을 사용한다.
