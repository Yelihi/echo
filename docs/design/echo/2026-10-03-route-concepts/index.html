APPROVED DESIGN / 2026-10-03

하나의 Echo, 연결되는 화면들.

참고 이미지 1–3의 흰색·차콜·레드, 큰 타이포그래피와 얇은 구분선을 이미지 4의 사이드바 중심 작업 구조에 적용한 데스크톱 시안입니다.

현재 페이지 경로 21개 → 시안 19장. 사용자 화면 17장, 개발 테스트 1장, 공통 404 제안 1장입니다. 이미지를 누르면 원본을 확대할 수 있습니다.

디자인 논의용 생성 이미지이며 실제 실행 화면이나 구현 결과가 아닙니다. 문구·샘플 수치·세부 세부 표현보다 실제 기능과 접근성을 우선합니다. 구현 화면은 Storybook의 Route Gallery에서 확인할 수 있습니다.

참고 이미지와 검토 범위

참고 1 · 참고 2 · 참고 3 · 참고 4

기존 페이지와 해당 view 코드를 읽어 화면별 역할을 대응했습니다. 새 AI 회화·문장 연습장 등 아직 연결되지 않은 기능은 이 라우트 세트에 포함하지 않았습니다. 두 연습의 준비·녹음 화면은 사이드바를 접는 방향입니다.

구현 규격은 implementation-20261003/design-contract.md에 기록합니다. 문단 AI 기능은 입력한 원문의 문단 나누기 제안이며 새 원문 생성 기능을 뜻하지 않습니다. 결과의 비교 표시는 음성 인식 문장을 기준으로 하며 발음 점수가 아닙니다.
